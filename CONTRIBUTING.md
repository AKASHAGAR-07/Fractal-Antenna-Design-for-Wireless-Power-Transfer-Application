# Contributing Guidelines

Thank you for your interest in contributing to the **Fractal Antenna Design for Wireless Power Transfer Application** project!

We welcome contributions from researchers, RF engineers, and developers to improve the simulation scripts, mathematical calculators, and documentation.

---

## 🛠️ How to Contribute

### 1. Reporting Bugs / Requesting Features
- Open an Issue on GitHub.
- Clearly describe the bug or the requested feature, including operating system, Python version, and simulation software version (ANSYS HFSS/Fusion 360).

### 2. Proposing Changes
1. **Fork the Repository**: Create a personal fork on GitHub.
2. **Clone the Fork**: Clone it locally on your computer.
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Implement and Test**:
   - Write/modify code in `src/` (e.g., calculations or plotting scripts).
   - Verify that all scripts run without errors.
5. **Commit and Push**:
   ```bash
   git commit -m "Describe your changes clearly"
   git push origin feature/your-feature-name
   ```
6. **Open a Pull Request**: Submit your pull request to the `main` branch of the parent repository.

---

## 💻 Code Style Guidelines
- **Python**: Follow PEP 8 guidelines. Check code formatting with `black` and linting with `flake8`.
- **Documentation**: Keep all equations formatted in standard LaTeX inside markdown files.
